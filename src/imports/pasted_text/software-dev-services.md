Design a modern, professional, responsive **software development services website** for a technology company.

## Website Purpose

The website should allow customers to:

* Request Android/iOS app development
* Request web application development
* Upload/publish an existing app to Google Play Store
* Deploy websites/apps to AWS
* Deploy websites to normal shared hosting
* Request backend/API development
* Request database development
* Request bug fixing and maintenance
* Contact the developer directly
* Submit a development requirement through a contact/order form

The website should feel trustworthy, modern, affordable, and suitable for students, startups, small businesses, creators, and companies.
